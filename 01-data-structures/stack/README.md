### 주식가격 풀이 후기
처음에는 **전체 시간 중 가격이 떨어지지 않은 시간**을 구하는 문제로 잘못 이해했다. 그래서 이전 가격과의 변화량을 스택에 저장하고, 변화량의 누적값을 이용해 유지 시간을 계산하려 했다.

하지만 실제로 **각 시점의 가격을 기준으로 처음 가격이 떨어지는 순간까지 걸린 시간**을 구하는 문제였다.

따라서 스택에 가격의 인덱스를 저장하며 현재 가격이 스택 가장 위의 최근 시점 가격보다 낮아지는 순간 '해당 인덱스를 pop하여 현재 인덱스 - 이전 인덱스로 시간을 계산하여 할당'하는 것을 그 전의 모든 감소한 인덱스들까지 반복했다. 끝까지 스택에 남은 인덱스는 마지막 시점까지 가격이 떨어지지 않은 경우로 계산했다.

* 잘못된 접근: 가격 변화량과 누적값으로 유지 시간 계산
* 해결 방법: 인덱스를 스택에 저장하여 처음 가격이 떨어지는 시점 탐색
* 시간복잡도: O(N)
	* while문의 전체 실행 횟수도 최대 N번이므로 전체 시간복잡도는 O(N).
